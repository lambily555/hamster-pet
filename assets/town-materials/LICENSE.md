# Building surface textures

Created using WoodFloor051, Marble012 and Tiles074 from ambientCG.com, licensed under the Creative Commons CC0 1.0 Universal License.

- WoodFloor051: https://ambientcg.com/view?id=WoodFloor051
- Marble012: https://ambientcg.com/view?id=Marble012
- Tiles074: https://ambientcg.com/view?id=Tiles074
- Official licensing statement: https://docs.ambientcg.com/license/
- License: https://creativecommons.org/publicdomain/zero/1.0/

The nine runtime JPGs were resized from the official 1K JPG color, OpenGL normal and roughness maps to 512 x 512. No displacement is used, so geometry and collision do not change. Original archives are excluded. Clean clinic ceramic tiles are generated by project code, not supplied by ambientCG. All maps load locally, without runtime network access.
